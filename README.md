# AI House Price Estimator

This project is an AI-powered real estate valuation tool. It uses a Machine Learning model (Random Forest Regressor) to predict house prices based on various property specifications. The project includes a data processing and model training script, alongside an interactive web application built with Streamlit.

## Features

- **Data Cleaning & Feature Engineering:** Automatically parses and cleans raw real estate data (prices, carpet area, floor numbers, etc.).
- **Exploratory Data Analysis (EDA):** Generates insightful visualizations for data distribution, price vs. area, and price by location/furnishing/bathrooms.
- **Machine Learning Model:** Trains a Random Forest Regressor to provide accurate, non-linear price predictions.
- **Interactive Web App:** A sleek Streamlit interface where users can input property details to get an estimated price (in Lacs and Crores) along with visual market comparisons.

## ⚠️ Important Note for Evaluators (Upload Limitations)

Please note that **two components were intentionally excluded** from this GitHub repository due to upload constraints and best practices:

1. **The Trained Model (`models/house_price.pkl`):** The Random Forest Regressor generated by the notebook reached a file size of **245 MB**. Since GitHub limits web uploads to 25 MB and CLI pushes to 100 MB, the model file could not be uploaded. 
2. **The Raw Dataset (`data/house_prices.csv`):** As per standard software engineering practices, raw datasets are added to `.gitignore` to keep the repository lightweight. 

**How to run the project:** You will need to download the dataset and run the Jupyter notebook locally to generate the model. See the instructions below.

## Dataset Setup

The dataset used for this project contains detailed real estate listings including prices, carpet area, and location details. 

- **Source Link:** [House Price Dataset by Juhi Bhojani on Kaggle](https://www.kaggle.com/datasets/juhibhojani/house-price)

Before running the code, you must place the raw dataset in the correct folder:
1. Download the `house_prices.csv` dataset from the link above.
2. Create a folder named `data` in the root of the project (if it doesn't exist).
3. Place the `house_prices.csv` file inside the `data/` folder.

## Usage

### 1. Train the Model

Before running the application, you need to train the machine learning model. This step will also clean the data and generate exploratory data analysis (EDA) plots in the `eda_plots/` directory.

Run all cells in the Jupyter Notebook:
```
notebooks/house_price_model.ipynb
```
*Note: This will train the AI and automatically create the large `house_price.pkl` and `locations.json` in the `models/` folder.*

### 2. Run the Web Application

Once the model is generated from the previous step, you can start the Streamlit web application.

Run the following command in your terminal:
```bash
streamlit run app.py
```
This will start a local server and open the web app in your default web browser (typically at `http://localhost:8501`).

## Architectural Decision: Streamlit vs. React/FastAPI

During the initial planning phase, a decoupled architecture (React for frontend, FastAPI for backend) was considered. However, the architecture was pivoted to **Streamlit** for the following technical reasons:
1. **Unified Codebase:** Streamlit allows seamless integration of the Python Machine Learning pipeline directly with the UI, eliminating the overhead of maintaining a separate API layer.
2. **Data-Centric UI:** Streamlit natively supports rendering complex Pandas DataFrames and Altair charts, which are critical for the Exploratory Data Analysis (EDA) visualizations required in this project.
3. **Rapid Prototyping & Delivery:** For an AI-focused project, Streamlit significantly reduces development time, ensuring that the primary focus remains on model accuracy and data quality rather than web framework boilerplate.

## Model Metrics
