# AI House Price Estimator

This project is an AI-powered real estate valuation tool. It uses a Machine Learning model (Random Forest Regressor) to predict house prices based on various property specifications. The project includes a data processing and model training script, alongside an interactive web application built with Streamlit.

## Features

- **Data Cleaning & Feature Engineering:** Automatically parses and cleans raw real estate data (prices, carpet area, floor numbers, etc.).
- **Exploratory Data Analysis (EDA):** Generates insightful visualizations for data distribution, price vs. area, and price by location/furnishing/bathrooms.
- **Machine Learning Model:** Trains a Random Forest Regressor to provide accurate, non-linear price predictions.
- **Interactive Web App:** A sleek Streamlit interface where users can input property details to get an estimated price (in Lacs and Crores) along with visual market comparisons.

## Project Structure

```
├── app.py                 # Streamlit web application
├── train_model.py         # Script to clean data, train the model, and generate EDA plots
├── requirements.txt       # Python dependencies
├── data/
│   └── house_prices.csv   # Dataset containing house prices (required for training and app visualization)
├── models/
│   ├── house_price.pkl    # Trained Random Forest model (generated by train_model.py)
│   └── locations.json     # Extracted location names (generated by train_model.py)
└── eda_plots/             # Directory where EDA visualizations are saved
```

## Usage

### 1. Train the Model

Before running the application, you need to train the machine learning model. This step will also clean the data and generate exploratory data analysis (EDA) plots in the `eda_plots/` directory.

Run all cells in the Jupyter Notebook:
```
notebooks/house_price_model.ipynb
```
*Note: This will create `house_price.pkl` and `locations.json` in the `models/` folder.*

### 2. Run the Web Application

Once the model is trained, you can start the Streamlit web application to interact with the House Price Estimator.

Run the following command:
```bash
streamlit run app.py
```
This will start a local server and open the web app in your default web browser (typically at `http://localhost:8501`).
